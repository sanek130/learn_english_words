# Learn Words Bot

Telegram-бот на Node.js + MongoDB: списки слов на двух языках, тренировка с проверкой по буквам, процент готовности к экзамену, таблица лидеров.

Переменные окружения (на Render и локально):

| Имя | Зачем |
| --- | --- |
| `BOT_TOKEN` | токен от [@BotFather](https://t.me/BotFather) |
| `MONGODB_URI` | строка подключения MongoDB Atlas |
| `WEBAPP_URL` | публичный URL сервиса на Render, например `https://learn-words-bot.onrender.com` |

`WEBAPP_URL` нужен для webhook (Render не держит долгий polling стабильно). Отдельное Mini App не обязательно.

## Локальный запуск

```bash
copy .env.example .env
npm install
npm start
```

Без `WEBAPP_URL` бот идёт в long polling. С URL — поднимает webhook.

## Деплой на Render

1. Репозиторий на GitHub → [Render](https://render.com) → **New Web Service**.
2. Build: `npm install`, Start: `npm start`, Instance: Free.
3. Environment:
   - `BOT_TOKEN`
   - `MONGODB_URI`
   - `WEBAPP_URL` = `https://<имя-сервиса>.onrender.com` (после первого деплоя сохраните URL и задеплойте ещё раз, если URL узнали только после старта).
4. MongoDB: Atlas → Database → Connect → Drivers. В Network Access добавьте `0.0.0.0/0` (Render не даёт фиксированный IP на free).

Free-инстанс Render засыпает: первый апдейт после сна может идти 30–60 секунд.

## Настройка через BotFather

Откройте [@BotFather](https://t.me/BotFather) в Telegram.

1. `/newbot` — имя бота (как в списке чатов), затем username (латиница, оканчивается на `bot`).
2. Скопируйте токен вида `123456789:AAH...` → это `BOT_TOKEN`.
3. `/setdescription` — выберите бота, текст до 512 символов, например: «Списки слов на двух языках, тренировка по буквам, готовность к экзамену».
4. `/setabouttext` — коротко: «Учим слова. Списки, тесты, лидеры».
5. `/setuserpic` — по желанию, квадратное фото.
6. `/setcommands` — вставьте команды:

```
start - Открыть меню
menu - Главное меню
cancel - Отменить текущий шаг
```

7. `/setprivacy` — для личного бота оставьте **Enable** (в группах не читает чужие сообщения). Если будете учить в группе — **Disable**.
8. `/setjoingroups` — **Disable**, если бот только в личке.
9. Не включайте `/setinline`, если не нужна инлайн-выдача.
10. После деплоя webhook ставится сам. Проверка: `https://api.telegram.org/bot<TOKEN>/getWebhookInfo` — в `url` должен быть ваш Render.

Меню внутри бота — inline-кнопки (Назад / Отмена на каждом шаге), это не команды BotFather.

## Как пользоваться

1. «Новый список» → исходный язык → язык перевода.
2. Список слов с новой строки, затем такой же список переводов.
3. «Применить изменения».
4. Либо «Промпт для нейросети» → копируете текст в ChatGPT и вставляете два блока в бота по очереди.
5. «Тренировка»: письменно (разбор букв) или тест с кнопками.
6. «Готовность к экзамену» — среднее мастерство × покрытие практики, со слабыми словами.
7. «Лидеры» — топ по % полностью верных и по числу задач.

Проверка ответа не через `===`: нормализация регистра и диакритики, артикли, порядок слов, дефис/пробел, синонимы через `/`, расстояние Левенштейна и побуквенный разбор (`ok` / замена / лишняя / пропуск). ≥92% — верно, ≥75% — почти.
